# Page: Home

> Overrides `MASTER.md` for the landing page only.

## Pattern (UI UX Pro Max)
**Hero-centric + social proof**  
Sections (one job each): Hero → Stats → Featured grid → How it works → IDE preview → Tech → Testimonials → CTA → Footer

## Layout
- Full-bleed dark hero (`#0D0D0D`), brand name hero-level (Outfit bold)
- One headline, one supporting line, CTA group (Primary + Ghost)
- No cards in hero; no stat strip in first viewport if it fights the brand (stats start section 2)

## Motion
ALLOW: Text Effect (headline), In View (sections), Animated Group (featured), Scroll Progress  
BLOCK: Morphing Dialog, Magnetic, Glow spam

## CTAs
- Primary: Start Creating → create/signup  
- Ghost: Browse Gallery → `/sketches/`

## Light theme
Supported via existing theme toggle; keep purple CTAs, light surfaces from MASTER light tokens.
